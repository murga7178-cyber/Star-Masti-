STAR MASTI DOWNLOAD WEBSITE

Files:
- index.html: website page
- Star Masti.apk: the APK download file
- assets/wallet.jpg: wallet screenshot
- assets/daily-checkin.jpg: daily check-in screenshot

IMPORTANT:
Keep the folder/file structure unchanged when uploading to hosting. The download button points to "Star Masti.apk" in this same folder.

To publish with GitHub Pages:
1. Create a public GitHub repository.
2. Upload index.html, Star Masti.apk, README.txt, and the assets folder (including both JPGs) to the repository root.
3. Open repository Settings -> Pages.
4. Select Deploy from a branch, choose the main branch and / (root), then Save.
5. Wait for GitHub Pages to publish and open the provided website URL.

The APK is around 10.6 MB. Some hosting services may have limits or security warnings for APK files. If the host blocks the APK, upload it to a public file host and update the two download links in index.html to that direct file URL.
